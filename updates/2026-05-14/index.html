Paper ToolCUA: Towards Optimal GUI-Tool Path Orchestration for Computer Use Agents
Computer Use Agents (CUAs) can act through both atomic GUI actions and high-level tool calls, but this hybrid action space often leads to suboptimal execution paths. ToolCUA proposes an end-to-end agent designed to learn optimal GUI-Tool path selection through a staged training paradigm.
Xuhao Hu et al. · May 12, 2026 · arXiv

Paper Counterfactual Trace Auditing of LLM Agent Skills
Introduces Counterfactual Trace Auditing (CTA), a framework for measuring how skills change LLM agent behavior. Testing on SWE-Skills-Bench with Claude across 49 software engineering tasks revealed that skills substantially reshape agent behavior even when pass rates remain nearly unchanged.
Xiaolin Zhou et al. · May 12, 2026 · arXiv
LLM agent evaluation skill auditing benchmarking
Paper Executable Agentic Memory for GUI Agent
Proposes Executable Agentic Memory (EAM), a structured Knowledge Graph that shifts GUI planning from free-form generation to robust retrieval-and-execution process. EAM outperforms UI-TARS-7B by up to 19.6% on AndroidWorld while reducing token costs 6x relative to GPT-4o.
Zerui Qin et al. · May 12, 2026 · arXiv
GUI agents knowledge graphs memory systems MCTS
Paper ALGOGEN: Tool-Generated Verifiable Traces for Reliable Algorithm Visualization
Proposes a novel paradigm that decouples algorithm execution from rendering using Visualization Trace Algebra (VTA). LLM generates Python tracker that outputs VTA-JSON traces, while deterministic renderer compiles traces. Achieves 99.8% success rate vs 82.5% for end-to-end methods on LeetCode AV benchmark.
Kunpeng Liao et al. · May 12, 2026 · arXiv
algorithm visualization LLM hallucination code generation educational tools
Paper Intermediate Artifacts as First-Class Citizens
Argues that AI systems should preserve durable, inspectable intermediate artifacts (typed, structured, addressable, versioned, dependency-aware) rather than just final outputs. These artifacts make AI-generated work more inspectable, revisable, and maintainable over time for multi-step AI workflows.
Josh Rosen, Seth Rosen · May 12, 2026 · arXiv

Blog OpenAI's WebRTC Problem for Voice AI
Luke Curley identifies a critical issue with OpenAI's voice AI implementation: WebRTC is designed to degrade audio quality during poor network conditions to maintain low latency, but this is problematic for LLM voice interactions. When audio packets are dropped, the prompt becomes garbage and produces garbage responses.

Blog Using Claude Code: The Unreasonable Effectiveness of HTML
Thariq Shihipar from Anthropic's Claude Code team advocates for HTML over Markdown as an output format for LLMs. The article demonstrates how requesting HTML output enables rich interactive explanations with SVG diagrams, interactive widgets, and in-page navigation.
