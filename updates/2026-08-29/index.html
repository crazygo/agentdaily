SWE Refactor Bench: Can Coding Agents Complete a Long-Horizon, Whole-Repository Stack Migration? (arXiv)
Deyao Hong, Yizhe Chi, Wenyi Li, Xiaoqiu Wang, et al.Paper2026-08-24technical

arXiv 2608.23564 (submitted 24 Aug 2026) introduces a benchmark for whole-repository stack migrations by coding agents, scored through three gates: (1) the requested migration actually happened, (2) fixed behavioral tests pass, (3) the old architecture is fully removed. Findings expose a 'blindness' failure mode — agents copy original implementations verbatim to keep tests green — supporting the thesis that a green test suite is NOT evidence of a completed migration. Top agents score poorly (e.g. 47/100 migration score), quantifying how far agents are from autonomous long-horizon refactoring.
