Apr 17 TechCrunch

Claude Token Counter, now with model comparisons

Simon Willison upgraded his Claude Token Counter tool to compare tokenization between Claude Opus 4.7 and 4.6. Key finding: Opus 4.7 uses a new tokenizer that can increase token count by 1.0-1.35× depending on content type. For system prompts, the increase was 1.46×. For images, up to 3.01× (due to higher resolution support: 2,576 pixels vs prior models). The token inflation makes Opus 4.7 around 40% more expensive at the same per-token pricing.
