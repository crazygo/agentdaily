Mitchell Hashimoto: Programming Languages Are Increasingly Not Lock-In

Mitchell Hashimoto on Bun migrating from Zig to Rust: 'On the interesting side is how fungible programming languages are nowadays. Programming languages used to be LOCK IN, and they're increasingly not so. You think the Bun rewrite in Rust is good for Rust? Bun has shown they can be in probably any language they want in roughly a week or two. Rust is expendable. Its useful until its not then it can be thrown out.' Simon Willison connects this to a conversation about a company using coding agents to rewrite both iPhone and Android apps to React Native - they chose React Native not because AI couldn't maintain separate apps, but because if it was wrong, they could 'just port back to native' in the future. The cost of language/framework migration has collapsed with AI assistance, fundamentally changing the calculus of technology choices.
