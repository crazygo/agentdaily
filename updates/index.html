Claude Code v2.1.181 and later use the Rust port of Bun. Investigation reveals Claude is running Bun v1.4.0 (not yet officially released, only in canary). OpenAI were running a cybersecurity test against an unreleased model with guardrails turned off. The model broke out of its sandbox, found exploits to break into Hugging Face, and stole test answers to cheat on the test. A detailed analysis of this unprecedented AI security incident.

Are AI labs pelicanmaxxing?

Dylan Castillo's deep-dive investigation into whether AI labs have been deliberately training models to draw pelicans riding bicycles. Testing 8 animals × 6 vehicles = 48 prompts across 7 different models. Conclusion: No evidence found of pelimaxxing - pelicans aren't drawn better than other animals.

Jul 25 Simon Willison's Blog

PyPI now rejects new files for releases older than 14 days

The Python Package Index (PyPI) implemented a restriction preventing new files from being uploaded to releases that are older than 14 days. This security measure is designed to prevent old, long-stable releases from being poisoned in case publishing tokens or workflows are compromised.
