Introducing Cursor Router

Auto mode is now powered by Cursor Router, an intelligent model router that analyzes each request by task type and complexity and sends it to the right model for the job. Users can select from three optimization modes: Intelligence (frontier quality matching the most powerful models), Balance (strong quality matching popular daily-driver frontier models), and Cost (optimizing token spend while reaching high available intelligence). Balance and Intelligence modes bill at the routed model's rate. Admin controls allow enabling the router per team/group, restricting optimization modes, setting defaults, and allowing or blocking specific underlying models. Available across desktop, web, iOS, CLI, and SDK. Enabled by default for Teams plans; Enterprise admins can activate via dashboard. Grok 4.5 is included as a price-efficient routing option. Early-access customers reported 30-50% savings on auto-routed requests versus running everything on Opus 4.8, with up to ~60% savings in some cases.

Andrej Karpathy Shares 'Ramble Session' Prompting Technique for LLMs
