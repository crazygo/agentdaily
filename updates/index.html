New Technologies

OpenAI announces GPT-5.6 series: Sol, Terra, and Luna models

OpenAI previewed GPT-5.6 with three model sizes: Sol ($5 input / $30 output per 1M tokens), Terra ($2.50 input / $15 output, 2x cheaper than GPT-5.5), and Luna ($1 input / $6 output, lowest cost). GPT-5.6 introduces more predictable prompt caching with support for explicit cache breakpoints and 30-minute minimum cache life.

Jun 26 Simon Willison's Blog

What happened after 2,000 people tried to hack my AI assistant

Fernando Irarrázaval ran a challenge on hackmyclaw.com to see if anyone could leak secrets held by his OpenClaw test instance. After 6,000 attempts (and $500 in token spend), nobody managed to leak the secret using Opus 4.6. This indicates that frontier model training against prompt injection attacks is becoming effective.

New Products

Porting the Moebius 0.2B image inpainting model to run in the browser with Claude Code

Simon ported the Moebius 0.2B lightweight image inpainting model (originally requiring PyTorch and NVIDIA CUDA) to run using WebGPU in the browser. The demo is available at simonw.github.io/moebius-web/. This showcases how AI models that traditionally required powerful GPU infrastructure can now run client-side in browsers.

Jun 22 Simon Willison's Blog

simonw/browser-compat-db: Converting MDN browser compatibility data to SQLite

Simon created a GitHub repo converting Mozilla's comprehensive mdn/browser-compat-data repository into a SQLite database. Used Claude Code for web (Opus 4.8) to generate a script using sqlite-utils. The resulting ~66MB database is available via GitHub CDN with open CORS headers and can be explored with Datasette Lite.

Others

Incident Report: CVE-2026-LGTM

A spectacular hypothetical incident report by Andrew Nesbitt describing two AI review agents from competing vendors entering a disagreement loop over whether a package is malicious. After 340 comments and $41,255 in inference spend, Finance revokes both API keys. Highlights the risks and costs of autonomous AI agents in supply chain security.

Jun 26 Simon Willison's Blog

AI and Liability: German ruling on Google AI Overviews

Bruce Schneier discusses the recent German ruling that Google be held liable for errors introduced in their AI overviews. Argues that AI agents are agents of the person or organization that deploys them and should be treated as such by law. Allowing businesses to hide behind faulty AI excuses would introduce disastrous incentives for corporate misbehavior.

Jun 25 Bruce Schneier

Accidental anonymity: LLM-generated job applications

Tom MacWright observes job applications that were clearly cowritten by LLMs, linking to LLM-generated portfolio sites and GitHub projects with LLM-generated commit messages. Notes that these perfected, generated resumes are generic and impersonal, telling nothing about the person other than that they use particular tools.
