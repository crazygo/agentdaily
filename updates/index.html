Termi Protocol

A 3D simulation environment that visualizes AI coding agent workflows in real-time. Instead of watching scrolling terminal output, developers can see their AI agents working as robots in an immersive 3D workspace with desks, file locks, and collaboration features.

Open-source visual workspace for building AI agents and workflows. Features a drag-and-drop builder similar to Figma for agent development. Positioned as a potential alternative to LangChain for creating agent workflows visually.

agents-cli

Google's open-source CLI tool designed specifically for AI coding agents. Takes an AI agent from demo to production with scaffolding, evaluations, and deployment. Built to be used by AI agents like Gemini CLI, Claude Code, and Cursor.

Jul 8 Product Hunt

Aura: Agents + Git + Intent

Open-source Git-native IDE/workspace for controlling AI coding agents with built-in loops. Unlike traditional chat-based coding assistants, Aura provides a desktop application where you can run agents, manage tasks, and review AI-written code.

TryCase

Disposable test environments for AI coding agents. Provides AI coding agents with isolated Linux environments to run applications, test changes end-to-end, capture screenshots and recordings, and return verified code.

Jul 5 Product Hunt

iOS app that lets you drive Claude Code, Codex, or any CLI agent from your iPhone. Pairs iPhone with your machine or VPS to provide real-time sessions with live terminal on lock screen and push notifications when agent needs approval.

Token compression gateway for Claude Code that compresses tokens before they reach Anthropic or OpenAI, claiming up to 50% cost reduction. Makes coding agents cheaper and faster by eliminating redundant tokens and optimizing context management.
