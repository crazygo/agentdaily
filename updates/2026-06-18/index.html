New Products
Zot
A lightweight, single-binary coding agent harness written in Go. Works with 20+ AI providers including Anthropic, OpenAI, Gemini, and local models. Features include four built-in tools (read, write, edit, bash), extensions via subprocess + JSON-RPC, swarm mode for background subagents, and Telegram bridge.

OpenYabby
Open-source voice-driven multi-agent assistant for macOS. Combines OpenAI Realtime API for voice with CLI runners (Claude Code, Codex, Aider, etc.) to execute real tasks. Features hierarchical multi-agent orchestration, persistent memory with Mem0 + Qdrant, 30+ connectors, and multi-channel support including WhatsApp-native agent threads.

Claw Patrol
Open-source security firewall for AI agents released by Deno. Sits between agents and production systems to parse and gate HTTP, SQL, Kubernetes, and SSH protocols. Addresses the critical security need of limiting AI agent access to sensitive data and systems.

VEXI
Open-source AI coding agent for the terminal with Product Hunt launch on June 15, 2026. Bring-your-own-api-key model supporting OpenAI, Anthropic, and other providers. Built specifically for developers who prefer terminal-based workflows.

Mira
Self-hosted AI code reviewer providing an open-source alternative to CodeRabbit and Greptile. Reviews pull requests using any LLM via LiteLLM with low-noise filtering including confidence thresholds, deduplication, and severity sorting. Apache 2.0 licensed.
