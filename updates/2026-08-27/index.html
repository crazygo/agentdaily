New Products · 9 launches

Fresh tools & agents spotted across Show HN, Reddit, X and trade press.

  1. Huzzah (danielvaughn.dev)

    2026-08-20·AI coding editor / workflow experiment·Show HN, Reddit, X

    AI coding platform built around the patent-pending Adronite Context Engine, which builds a live relational model of the whole codebase before generating code — claims ~48% fewer tokens and fewer hallucinations, works with frontier or self-hosted open-weight models including air-gapped deployments.

    2026-08-19·AI coding platform·DevOps.com, Yahoo Finance, DEVOPSdigest

  3. Saggar (saggar.marginalutility.dev)

    Native macOS terminal app for developers running AI coding agents: runs shells, dev servers, tests and agents (Claude, Codex etc. via ACP) while surfacing which session actually needs your attention.

    2026-08-17·terminal for AI coding agents·Show HN

    Built because the author’s terminal stopped feeling like a tool and started feeling like a tab-management problem. — author, Show HN

  4. Proliferate (github.com)

    Open-source, self-hostable Codex-style environment that hosts any coding agent (Claude Code, Codex, OpenCode), orchestrating parallel tasks in isolated worktrees with built-in review.

    2026-08-21·open-source self-hosted coding-agent host·Show HN

  5. Deltix (app.deltix.ai)

    AI agent that tests mobile apps by completing plain-English user tasks inside an iOS Simulator on your own Mac; successful runs become replayable regression checks. Local-first: never accesses source, build or signing identities.

    2026-08-15·AI testing agent (mobile QA)·Show HN

  6. MCP Memory (github.com)

    Fast persistent agent memory exposed over MCP, built on Google’s OKF plus SQLite FTS5, letting coding agents store and recall project knowledge across sessions cheaply.

    2026-08-13·agent workspace memory (MCP server)·Show HN

  7. Compartment Up (up.compartment.dev)

    Free hosting service designed so AI coding agents (Claude Code, Codex, Cursor) are the primary users: an agent reads machine-readable terms, registers itself, writes compartment.yml and deploys — returning a live URL without any human account.

    2026-08-19·agent-native deployment workflow·Show HN

  8. Knowl (github.com)

    Self-pruning memory layer for Claude Code: splits project knowledge into typed atoms and flags stale entries as superseded instead of letting CLAUDE.md-style memory grow past 1000 lines.

    2026-08-22·project-long agent memory·Show HN

    Author argues existing memory tools only append and do not fix what is stale. — Show HN discussion

  9. CommitLore (github.com)

    Git-aware memory for coding agents that preserves the decisions behind commits so agents stop re-forgetting project context between sessions.

    2026-08-19·project-long agent memory (git)·Show HN
