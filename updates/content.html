Codex CLI 0.128.0 Adds /goal Feature

OpenAI's Codex CLI introduces a /goal feature, similar to the Ralph loop pattern. Users can now set a goal and Codex will continue looping until it evaluates that the goal has been completed or the configured token budget is exhausted.

LLM 0.32a0 Major Backwards-Compatible Refactor

Simon Willison released LLM 0.32a0, a major alpha release with consequential changes. Model inputs now represented as sequence of messages instead of simple prompts, and model responses can be composed of streams of differently typed parts including text, tool calls, reasoning, images, and audio.
