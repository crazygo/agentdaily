GitHub changed Copilot Individual plans, tightening usage limits and pausing signups. The announcement notes that agentic workflows have fundamentally changed compute demands, with long-running parallelized sessions consuming far more resources than the original plan structure supported.

Google: 75% of New Code is AI-Generated

Google CEO Sundar Pichai announced that 75% of all new code at Google is AI-generated, up from 50% last fall. Google created a 'strike team' to improve AI coding capabilities to catch up to Anthropic, which writes 70-90% of its code with Claude Code.

Claude Code Postmortem: Harness Bugs

Anthropic published a postmortem explaining that recent Claude Code quality issues were caused by three separate bugs in the Claude Code harness, not the models themselves. One key bug caused older thinking to be cleared from idle sessions repeatedly.

Discussion about how 'headless' services (API-first, no browser required) are becoming more common as personal AIs prefer APIs over GUIs. Salesforce announced Salesforce Headless 360, and Brandur Leach predicts APIs are ready for a comeback as agents need direct access to services.
