Ponytail

AI coding agent skill that prevents over-engineering by implementing a decision ladder forcing agents to evaluate options before writing code: (1) Does this need to exist? (2) Is it already in this repo? (3) Does standard library do it? (4) Does platform do it? (5) Does installed dependency do it? (6) Can it be one line? (7) Only then write minimum. Reports 54% less code generated, 20% cheaper to run, 27% faster execution, and up to 94% less code on tasks where agents typically over-build. Works with Claude Code, Codex, Copilot CLI, OpenCode, Cursor, and others via npm global install with commands like /ponytail [lite|full|ultra|off], /ponytail-review, /ponytail-audit, and /ponytail-debt.
