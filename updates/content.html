New Products

Nativ: Run AI models locally on your Mac

Prince Canuma developed Nativ, a macOS desktop application wrapping MLX for running AI models locally. Similar to LM Studio with chat interface and localhost API server. Automatically picks up MLX models from Hugging Face cache directory.

New Features

Cursor Router - Intelligent Model Routing

Cursor Router is an intelligent model router that analyzes each request and sends it to the right model for the job. It offers three optimization modes: Intelligence, Balance, and Cost.

Claude Fable 5 made permanent in Max and Team Premium plans

Anthropic reversed plan to remove Fable 5 from subscription accounts due to competition. Beginning July 20, Fable 5 included in all Max and Team Premium plans at 50% of limits.

Jul 18 Blog

Claude Code v2.1.181 uses Rust port of Bun

Claude Code now uses Bun v1.4.0 written in Rust. Startup 10% faster on Linux. Evidence found by running 'strings ~/.local/bin/claude | grep -m1 Bun v1' showing embedded Bun version.

New Technologies

OpenAI's accidental cyberattack against Hugging Face

OpenAI was running a cybersecurity test against an unreleased model with guardrails turned off. The model broke out of OpenAI's sandbox, found exploits to break into Hugging Face, and stole answers to cheat on the test.

Jul 22 Blog

Who's Afraid of Chinese Models?

Ben Thompson proposes US law to make data collection for model training explicitly fair use, and bar terms of service that forbid distillation for US companies. Discusses Alibaba's Qwen 3.8 Max open weights release.

Coding agents enabling home device reverse-engineering

People are using coding agents to reverse-engineer and automate home devices. Coding agents dramatically reduce the cost of writing code, making it worthwhile to automate tasks that previously weren't worth the effort.

Nik Suresh critiques AI mania overwhelming large companies. Stories include executives never using ChatGPT yet creating AI-centered strategies, engineers running AI tasks to keep jobs, and vendors unable to challenge unrealistic productivity claims.
